# Spedger
Web application which offers users a platform to record sports predictions and connect with other users without spending any money.

The goal is to enable users get a somewhat fun experience of predicting games without having to deal with the financial setbacks. This tool neither accepts money nor does it give out any form of cash prize. It simply logs predictions.

The tool also is not to be mistaken as a betting tool. The tool unfortunately does not offer users directly the avenue to predict the games. Users would have to book the game at https://sportybet.com and input the code to get started.
